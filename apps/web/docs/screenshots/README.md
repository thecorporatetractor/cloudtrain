## Platform views (`platform/`)

Captured by `scripts/platform-shots.mjs` with one mock persona per area. The public website (signed out): `landing` (+ `-phone`, `-tablet`), `site-menu-phone`, `catalog-public` (+ `-domain`, `-phone`), `catalog-path-public`, `catalog-exam-public`, `features` (+ `-phone`, `-lightbox`; `coming-soon-features` is the landing callout, `coming-soon-features-page` the page in coming-soon mode), `pricing` (+ `-yearly`, `-phone`), `about`, `faq`, `contact`, `legal-terms`, and `site-signed-in` (the website header once signed in). Billing (mock Stripe, test mode): `account-billing` (+ `-subscribed`, `-phone`), `admin-billing`. Then: `sign-in` (+ `-sso`, `-password`, `-expired`), `forbidden`, `home-learner`, `assignments`, `history` (+ `-attempt`), `exams`, `user-menu`, `persona-switcher`, `team-dashboard`, `team-member`, `team-assign`, `team-assignments` (+ `-detail`), `team-exams`, `cohorts`, `cohort-board`, `cohort-terminate`, `observe`, `workspace-observed`, `studio-author`, `admin-overview`, `admin-users`, `admin-user-edit`, `admin-invite`, `admin-deactivate`, `admin-teams`, `admin-sso` (+ `-connection`, `-wizard`), `admin-content`, `admin-sessions`, `admin-usage`, `admin-audit` (+ `-detail`), `admin-settings`, `platform-orgs`, `platform-org`, `platform-capacity`, `platform-content`. Dark for all; light and cream for landing, the features callout and page, catalog-public, pricing, sign-in, team dashboard, cohort board, admin users and SSO; `-1280` variants for the three widest tables.

The screens the website itself shows are not here: `scripts/site-shots.mjs` and `scripts/feature-shots.mjs` capture them as WebP into `apps/web/public/site/` (the features page's under `site/features/`, 1x and 2x, dark and light, with the mock persona switcher hidden).
